# Responsive Design

Responsive design makes a website adapt to different screen sizes.

```css
@media (max-width: 768px) {
    .navigation {
        flex-direction: column;
    }
}
```

## Practical Checklist

- Use flexible widths.
- Prefer responsive grids/flexbox.
- Avoid unnecessary fixed heights.
- Test mobile, tablet, and desktop sizes.
- Make buttons and text comfortable to use on small screens.
