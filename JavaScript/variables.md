# JavaScript Variables and Data Types

JavaScript commonly uses `let`, `const`, and older code may contain `var`.

```javascript
let username = "Sawaira";
const country = "Pakistan";
let age = 20;
```

## Common Data Types

- String
- Number
- Boolean
- Undefined
- Null
- Object
- Array
- BigInt
- Symbol

Prefer `const` when a variable does not need reassignment.
