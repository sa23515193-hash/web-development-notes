# HTML Forms

Forms collect user input.

```html
<form>
    <label for="name">Name</label>
    <input id="name" type="text" name="name">

    <label for="email">Email</label>
    <input id="email" type="email" name="email">

    <button type="submit">Submit</button>
</form>
```

## Common Input Types

- text
- email
- password
- number
- date
- file
- checkbox
- radio
