# HTML Notes

HTML (HyperText Markup Language) is used to structure content on web pages.

## Topics

- Document structure
- Headings and paragraphs
- Links and images
- Lists
- Tables
- Forms
- Semantic HTML
- Multimedia

## Basic Structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>My first webpage.</p>
</body>
</html>
```

## Common Tags

| Tag | Purpose |
|---|---|
| `<h1>` | Main heading |
| `<p>` | Paragraph |
| `<a>` | Link |
| `<img>` | Image |
| `<ul>` | Unordered list |
| `<ol>` | Ordered list |
| `<form>` | Form |
| `<button>` | Button |
