# HTML Tables

Tables represent tabular data.

```html
<table>
    <thead>
        <tr>
            <th>Name</th>
            <th>Role</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Sawaira</td>
            <td>Web Developer</td>
        </tr>
    </tbody>
</table>
```

Use tables for data, not for general page layout.
