# Git and GitHub Notes

Git is a version control system. GitHub is a platform for hosting and collaborating on Git repositories.

## Basic Workflow

```text
Make changes
    ↓
git status
    ↓
git add .
    ↓
git commit
    ↓
git push
    ↓
GitHub
```

## Common Commands

```bash
git init
git status
git add .
git commit -m "message"
git branch
git switch main
git pull
git push
git clone URL
```
