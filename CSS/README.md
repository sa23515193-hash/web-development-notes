# CSS Notes

CSS (Cascading Style Sheets) controls the presentation and layout of web pages.

## Topics

- Selectors
- Colors
- Typography
- Box Model
- Flexbox
- CSS Grid
- Positioning
- Responsive Design
- Media Queries

## Example

```css
.card {
    width: 300px;
    padding: 20px;
    border-radius: 12px;
    margin: 20px;
}
```

## Box Model

Every element can be understood as:

`Content → Padding → Border → Margin`
