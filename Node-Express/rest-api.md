# REST API Basics

A REST-style API exposes resources through URLs and HTTP methods.

Example resource:

```text
/api/products
/api/products/:id
```

Typical operations:

```text
GET    /api/products
GET    /api/products/:id
POST   /api/products
PUT    /api/products/:id
DELETE /api/products/:id
```

Use appropriate HTTP status codes and consistent JSON responses.
