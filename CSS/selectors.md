# CSS Selectors

Selectors target HTML elements.

```css
p {
    color: black;
}

.card {
    padding: 20px;
}

#main-title {
    font-size: 32px;
}
```

## Common Selectors

| Selector | Example |
|---|---|
| Element | `p` |
| Class | `.card` |
| ID | `#header` |
| Attribute | `input[type="email"]` |
| Descendant | `.card p` |
