# Semantic HTML

Semantic elements describe the meaning of their content.

Common elements:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

Example:

```html
<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
</nav>

<main>
    <section>
        <h2>Projects</h2>
        <p>My web development projects.</p>
    </section>
</main>

<footer>
    <p>Copyright 2026</p>
</footer>
```

Semantic HTML improves structure, accessibility, and maintainability.
