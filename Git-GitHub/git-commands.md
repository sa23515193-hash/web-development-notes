# Git Commands

## Start a repository

```bash
git init
```

## Check changes

```bash
git status
```

## Stage files

```bash
git add .
```

## Commit

```bash
git commit -m "Add notes"
```

## Connect remote

```bash
git remote add origin REPOSITORY_URL
```

## Push

```bash
git push -u origin main
```

## Pull latest changes

```bash
git pull
```
